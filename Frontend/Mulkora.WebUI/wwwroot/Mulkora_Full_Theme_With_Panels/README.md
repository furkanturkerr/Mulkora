# Mülkora Full HTML Theme

Modern emlak platformu için hazırlanmış saf HTML, CSS ve JavaScript tema paketi. Herhangi bir framework veya .NET kodu içermez.

## Klasörler
- Kök dizin: Kullanıcı tarafı (ilan, detay, randevu, hesap, hata ve kurumsal sayfalar)
- `admin/`: Yönetici paneli ekranları
- `agent/`: Emlak danışmanı paneli ekranları
- `assets/css/theme.css`: Kullanıcı tarafı tasarım sistemi
- `assets/css/dashboard.css`: Admin ve danışman paneli tasarım sistemi
- `assets/js/theme.js`: Kullanıcı tarafı etkileşimleri
- `assets/js/dashboard.js`: Panel etkileşimleri

## Başlangıç
Tüm ekranlara ulaşmak için `all-pages.html` dosyasını açın.

## Panel sayfaları
### Admin
Genel bakış, ilanlar, ilan onayı, randevular, danışmanlar, kullanıcılar, kategoriler, mesajlar ve ayarlar.

### Danışman
Genel bakış, ilanlarım, ilan ekleme/düzenleme, randevular, takvim, mesajlar ve profil.
